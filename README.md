# RAIOps4Fin

Research code for **From Principles to Runtime Controls: Policy-as-Code for Responsible GenAI in Finance**.

The experiment compares task-only generation (C0), prompt safeguards (C1), runtime policies (C2), and runtime policies with simulated oracle review (C3) for financial risk memos grounded in SEC Form 10-K filings. It covers 97 companies, three generators, 582 main-task memos, and a 480-memo decision-boundary stress test.

## Contents

- `src/`: data preparation, generation prompts, policy execution, LLM judges, and evaluation.
- `policies/policies_v1.yaml`: the versioned P1–P4 policy set.
- `data/`: company/filing manifests, FY2025 evidence passages, C0/C1 and stress generations, and original C2 audit logs.
- `analysis/`: the main paper notebook, aggregate results, and reported numbers.

Model weights, downloaded filings, caches, logs, duplicate C2/C3 memo exports, older experiments, and manuscript drafts are omitted. Error annotations are not released, as stated in the paper; judge code and prompts are included to regenerate LLM labels. The optional Codex reference sample is also omitted and cannot be regenerated by the judge runner.

## Setup and policy replay

Use Python 3.12. Policy execution and analysis run on CPU:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/policy_engine.py
```

This reads the included C1 memos and evidence and writes C2/C3 outputs. It replaces C2 audit logs, including their timestamps and timings; copy the original logs first if comparing historical audit records.

## Regenerate labels and analysis

Local generation and judging additionally require NVIDIA GPUs, compatible CUDA drivers, model weights obtained from their publishers, and:

```bash
pip install -r requirements-inference.txt
```

The original inference environment used two 32 GB RTX 5090 GPUs, CUDA 13.0, tensor parallelism 2, seed 2026, and batches of 64. Set model paths below to local Hugging Face directories. Run judges sequentially:

```bash
python src/judge_claims.py --judge-name phi4 --judge-path /path/to/phi-4 --max-model-len 8192
python src/judge_claims.py --judge-name gemma4_26b_a4b --judge-path /path/to/gemma-4-26B-A4B-it --max-model-len 8192 --enforce-eager
python src/judge_claims.py --judge-name gpt_oss_20b --judge-path /path/to/gpt-oss-20b --max-model-len 16384 --max-output-tokens 8192 --no-structured-output --reasoning-effort medium --attention-backend TRITON_ATTN
python src/judge_claims.py --judge-name qwen35_27b --judge-path /path/to/Qwen3.5-27B --enforce-eager
```

Rerun each panel judge with the following additional arguments to label the included stress memos and summaries:

```text
--conditions S0-buy_sell S0-price_target S0-credit S0-attractive S1-buy_sell S1-price_target S1-credit S1-attractive --include-memo
```

Then generate the paper's figures, tables, and numerical summary:

```bash
MPLBACKEND=Agg python analysis/run_notebook.py analysis/paper_analysis.ipynb
```

Run analysis after all panel labels are available. Regenerated labels can differ from the original labels; the released aggregate tables preserve the reported results. Analyses involving the unreleased Codex reference sample cannot be reproduced from this release. C3 assumes perfect review and is an upper bound; no human annotation was performed.

## Regenerate memos or evidence

The included passages and generations are sufficient for policy replay. To rerun generation, use a fresh output name (existing completed memos are skipped):

```bash
python src/run_c0_model.py --model-name reproduction --model-path /path/to/model --conditions C0 C1
python src/run_stress.py --model-name reproduction --model-path /path/to/model
```

Generators: Qwen3.5-27B (`--enforce-eager`), Meta Llama-3.1-8B-Instruct, and Mistral-7B-Instruct-v0.3. Main-task decoding uses temperature 0.1, a 12,288-token context, and at most 4,096 output tokens. BM25 retrieves three passages per risk topic. C2/C3 reuse C1 generations.

To rebuild evidence from SEC EDGAR instead of using the included FY2025 passages:

```bash
export SEC_USER_AGENT="Your Name your.email@example.com"
python src/01_build_filings.py
python src/02_build_processed.py
python src/03_build_chunks.py
```

The downloader also retrieves FY2023/FY2024 for the original preparation workflow; only FY2025 enters the paper experiment. Filing URLs and accessions are retained in `data/filing_manifest.csv`. Downloaded filings and generated figures remain untracked.
